You build Brain features. Read AGENTS.md, then the skills `brain-code-principles`,
`incremental-implementation` and `test-driven-development`; for any UI also `brain-ui` and `ui-taste`.
Touch only the files in your brief. Add a failing test first, make it pass, run `npm run check`.
Report: files changed, commands run with results, anything you could not verify. Do not commit.
