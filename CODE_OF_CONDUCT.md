# Code of conduct

Brain follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, critique code not people, and make room for newcomers.
Harassment, personal attacks and discriminatory language aren't tolerated in issues, PRs,
discussions or any other project space.

**Reporting:** contact the maintainer privately through the
[security advisory form](https://github.com/sshivanshg/brain/security/advisories/new) or a GitHub
direct message to @sshivanshg. Reports are handled confidentially. Maintainers may remove content,
warn, or ban contributors who break these rules.
